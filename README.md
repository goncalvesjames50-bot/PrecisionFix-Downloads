# PrecisionFix

Downloads oficiais do PrecisionFix para Windows.

## Transferir

Descarrega a versão mais recente na página de [Releases](https://github.com/goncalvesjames50-bot/PrecisionFix-Downloads/releases/latest). Na página da versão, abre **Assets** e seleciona o instalador `.exe`.

### Versão atual: 1.7.1

- **Sistema:** Windows x64
- **Instalador:** `PrecisionFix.Setup.1.7.1.exe`
- **Tamanho:** aproximadamente 110 MiB
- [Descarregar o instalador](https://github.com/goncalvesjames50-bot/PrecisionFix-Downloads/releases/download/v1.7.1/PrecisionFix.Setup.1.7.1.exe)

## Instalação

1. Transfere o instalador a partir da página oficial de Releases.
2. Abre o ficheiro `.exe` e segue as instruções apresentadas.

O instalador não está assinado digitalmente. Por isso, o Windows SmartScreen poderá apresentar um aviso. Confirma que transferiste o ficheiro desta página oficial antes de prosseguir.

## Verificar o ficheiro

SHA-256 do instalador da versão 1.7.1:

```
a4f7aea8a0ee5d7eac8a82b6cb109e0c57a5cb18d98663234312da852b43d965
```

No PowerShell, podes calcular o hash do ficheiro transferido com:

```powershell
Get-FileHash ".\PrecisionFix.Setup.1.7.1.exe" -Algorithm SHA256
```
